# Refine

Execute criticism loops to improve anything toward user-defined goals.

## Principles

User defines what "better" means. Critique current state fresh each iteration. Signal honestly when continuing may not add value.

## Stopping

User decides when to stop. Signal when improvements become marginal, changes risk removing necessary function, or goal appears achieved.
