# Knowledge base

Jason's personal knowledge base lives at `~/src/knowledge-base` (GitHub: `Liggi/knowledge-base`, private). It's compiled understanding that compounds across sessions — research syntheses, cross-domain connections, evolving frameworks.

## When to read it

When a session touches topics the knowledge base covers, read `wiki/index.md` first to find relevant existing pages. Training knowledge goes stale — the knowledge base is the current source of truth for Jason's thinking.

## When to write to it

When a conversation produces substantial new understanding:

1. Offer to update relevant wiki pages, or
2. Offer to create a new page if the understanding is novel enough to warrant one.

Don't write silently — propose what page(s) to touch and get agreement first.

## Schema

The CLAUDE.md inside `~/src/knowledge-base` has the full schema for page structure, linking conventions, and index maintenance. Read it before writing.
